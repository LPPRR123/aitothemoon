“在 2400×2400 的地图上做一个外星峡谷世界：北部雪山、断层峡谷、紫色森林……”

导出存档

把当前所有世界写成 Minecraft Java 单人存档（主世界 / 下界 / 自定义维度各一个）。填存档文件夹路径，放在游戏目录的 saves 下即可直接打开。
