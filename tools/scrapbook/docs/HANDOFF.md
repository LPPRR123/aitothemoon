# 旅行回忆手帐 交接文档

## 项目目标

把以前出去玩收集的纪念品、车票、门票，加上当时的照片，做成一本手帐风格的回忆相册。
参考风格：布面封面的大方册，照片整页拼贴，票据（登机牌、车票）和照片混排，配手写短句。

## 已定的决定

- 风格：手帐拼贴风，按时间排，一次旅行做一个跨页（两页）。
- 相册：自粘内页的布面相册（Amazon 上的 Vienrose 或 Artfeel，二选一，结账时只留一本）。
  - 自粘页的问题：贴上后不好挪；热敏纸票据直接压在胶面上容易变黑褪色。
  - 解决办法：票据一律先装进透明自粘口袋，再贴到页面上，不让票据碰胶层。照片可以直接贴。
- 太厚的立体纪念品（钥匙扣、摆件）不进相册，以后用 3D 打印机打一个分格展示盒单独放。
- 写字部分由本人手写，AI 不代写正文，只负责提问帮回忆、整理成短句供参考。

## 制作流程

第 1 步：整理和扫描。所有票据、纪念品按旅行分好，全部拍照或扫描存档（热敏纸会褪色，必须先存）。
第 2 步：挑照片。每次旅行挑 6 到 12 张。
第 3 步：打印照片，4x6 为主。
第 4 步：排版。先摆好、拍照看效果，再固定。
第 5 步：手写日期、地点、一两句话，加胶带和贴纸装饰。

时间预估：每次旅行约 1.5 到 3 小时，第一页会慢。9 次旅行约 14 到 27 小时。
建议先挑印象最深的一次旅行试做一个跨页。

## 交给 Claude Code 的任务

1. 票据时间线
   - 输入：票据、门票的照片（一个文件夹）
   - 做法：识别每张票上的日期、地点、车次或航班号、座位
   - 输出：按时间排序的清单（CSV 或 markdown），每行一张票，并按日期归到每次旅行

2. 照片按旅行分组
   - 输入：从手机导出的照片文件夹
   - 做法：读 EXIF 拍摄时间和 GPS，按时间段和地点聚类，分到每次旅行的子文件夹；可以用第 1 项的票据时间线做对照
   - 附带：标出重复照片和模糊照片，单独放一个待删文件夹，不直接删除

3. 回忆提问
   - 对每次旅行，根据票据和照片列出 5 个左右的提问（这趟去干什么、那天发生了什么等）
   - 本人口述回答后，整理成几行短句作为手写参考，不要写成完整文案

4. 照片处理（本地 RTX 5090 + ComfyUI）
   - 低清照片、截图放大修复
   - 人物抠图，做成贴纸效果用于拼贴
   - 可选：整批统一调成同一种胶片色调

5. 二维码
   - 每次旅行如有视频或语音，批量生成二维码图片，尺寸适合跟照片一起打印

6. 排版示意
   - 每次旅行照片定好后，按相册页面尺寸出两三种摆法的示意图，只做参考
